# Тренажёр таблицы умножения

Веб-приложение для тренировки таблицы умножения в формате экзамена. За один раунд нужно ответить на 20 случайных вопросов и допустить не больше двух ошибок.

## Как запустить

Откройте файл `index.html` в браузере. Установка и подключение к интернету не требуются.

## Как проходит экзамен

- В каждом раунде — 20 случайных примеров.
- Используются все варианты умножения чисел от 2 до 9: от `2 × 2` до `9 × 9`.
- Для каждого примера предлагаются четыре варианта ответа.
- После правильного ответа автоматически появляется следующий вопрос.
- Если ответ неверный, тренажёр показывает правильный ответ и пояснение. Чтобы продолжить, нажмите **«Далее»**.
- Для сдачи экзамена нужно допустить не больше двух ошибок.
- После завершения раунда можно начать новый: вопросы перемешаются.
